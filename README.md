# Admin Service

Административный backend для управления юридическими лицами и B2B-операциями. Сервис предоставляет REST API для авторизации администраторов, организаций, пользователей, документов, кошельков, заказов, заявок на покупку и аналитики.

## Возможности

- авторизация администратора и работа с access/refresh JWT;
- управление организациями, пользователями и их кошельками;
- создание и получение мнемоник и производных секретных ключей кошельков;
- загрузка, хранение и выдача документов организации через S3-совместимое хранилище;
- работа с заказами и заявками на покупку;
- поиск контрагентов и аналитика по заказам и покупкам;
- ограничение частоты запросов, CORS и security-заголовки;
- структурированные логи и correlation ID для запросов;
- защищённая Basic Auth документация Swagger и ReDoc.

## Стек

- Python 3.12;
- FastAPI, Pydantic Settings, Granian;
- PostgreSQL через SQLAlchemy и asyncpg;
- Redis;
- S3-совместимое объектное хранилище через aiobotocore;
- JWT RS256 через `python-jose`;
- AES-GCM и `bip-utils` для работы с криптографическими данными кошельков;
- Docker и Docker Compose.

## API

Все прикладные маршруты находятся под префиксом `/v1`:

| Раздел | Префикс |
| --- | --- |
| Авторизация | `/v1/auth` |
| JWT | `/v1/jwt` |
| Организации | `/v1/organizations` |
| Документы организаций | `/v1/organizations/{organization_id}/documents` |
| Пользователи | `/v1/users` |
| Поиск | `/v1/search` |
| Заказы | `/v1/orders` |
| Заявки на покупку | `/v1/purchase-requests` |
| Аналитика | `/v1/analytics` |

Полная схема методов и моделей доступна в Swagger после запуска приложения.

## Структура проекта

```text
src/
	application/      бизнес-команды, контракты и доменная модель
	infrastructure/  база данных, Redis, S3, JWT, криптография и логирование
	presentation/    маршруты, схемы, middleware и зависимости FastAPI
	main.py          создание FastAPI-приложения и lifecycle
```

Приложение построено вокруг разделения presentation, application и infrastructure. Бизнес-операции реализованы в application commands, а доступ к внешним системам скрыт за контрактами и инфраструктурными адаптерами.
